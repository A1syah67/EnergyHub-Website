# EnergyHub

## Appliance Energy Use in Australia

EnergyHub is a simple educational website that explores household appliance energy use in Australia, with a focus on televisions. The website presents information through clear text, visual charts and simple explanations to help users understand TV technology, screen size, brands, star ratings and power consumption.

---

## Project Purpose

The purpose of EnergyHub is to present appliance energy information in a simple and user-friendly way. The project also provides an opportunity to practise web development skills using HTML, CSS and JavaScript while exploring and presenting data.

---

## Target Audience

EnergyHub is designed for:

- **TV Buyers** – people looking for a new television and comparing different options.
- **Energy Savers** – consumers who want to consider energy use when choosing a TV.
- **Everyday Users** – users who prefer simple visual information instead of technical details.

---

## Website Pages

### 1. Home

The Home page gives a simple introduction to appliance energy use in Australia. It includes quick facts about:

- Energy labels and star ratings
- Standby power
- Energy-efficient appliances

It also provides links to the Televisions and About Us pages.

### 2. Televisions

The Televisions page focuses on television energy use and presents findings from an Australian Government television energy dataset.

The data story investigates:

1. What TV screen technologies are available and which are most frequent?
2. What screen sizes are available and which are most frequent?
3. Which brands have the largest number of models?
4. Which screen technology consumes the least power?
5. What is the relationship between screen size and power use?
6. What is the relationship between star rating and screen size?
7. Are there differences in power consumption between brands?

The page also includes a conclusion about making a smarter TV choice.

### 3. About Us

The About Us page explains the purpose of EnergyHub and how the website was created as a learning project. It also includes information about the project's purpose and contact details.

---

## Data Story

The television data story uses charts to explore patterns in:

- Screen technology
- Screen size
- Brand and number of models
- Power consumption
- Star rating
- Relationships between different variables

The charts are presented with short explanations so users can understand the main findings without needing detailed technical knowledge.

---

## Key Findings

Some of the main findings presented on the Televisions page include:

- LCD (LED) is the most frequent screen technology in the dataset.
- Screen sizes range from 16" to 116", with 24" and 32" being the most common sizes.
- Kogan has the greatest number of different models in the dataset.
- LCD has the lowest power consumption among the screen technologies shown.
- Larger TVs generally tend to use more power.
- There is a weak negative relationship between star rating and screen size.
- Power consumption varies between different brands and between models of the same brand.

## GenAI Usage

Generative AI was used as a supporting tool during the development of EnergyHub.

It was used to help with:

- Writing and improving HTML structure
- Checking and cleaning up CSS
- Improving the organisation of the website layout
- Suggesting simple card layouts and styling ideas
- Reviewing JavaScript structure

The final website was reviewed and adjusted manually to match the project requirements, design preferences and data analysis.

### Notes on How GenAI Was Used

GenAI was mainly used for assistance rather than generating the entire project automatically. Existing code was provided and reviewed, then changes were made based on the project's requirements.

For example, GenAI helped organise the HTML into clearer sections such as the audience section, data story section and conclusion section. It also helped improve the CSS by creating a cleaner card-based layout while keeping the colours matched to the EnergyHub logo.

GenAI was also used to simplify the explanations of the charts so that the findings were easier for users to understand.

The generated suggestions were checked before being added to the website. Unnecessary code and content were removed or changed when they did not match the project's requirements.

---

## Reflection on Using GenAI

Using GenAI during this project was helpful because it made it easier to organise the website and improve the presentation of the content. It was especially useful when checking the structure of my HTML, cleaning up the CSS and finding simpler ways to explain the data findings.

One challenge was that some generated suggestions did not fully match my original design or project requirements. Because of this, I had to review the code carefully and make my own changes instead of copying everything directly.

Overall, GenAI helped me work more efficiently and gave me ideas for improving the website. At the same time, I learned that I still need to understand the code myself so I can check whether the suggestions are correct and suitable for my project.
